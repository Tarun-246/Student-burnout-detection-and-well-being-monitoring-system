# Vital

Vital is a web-based student well-being tracker designed to help students monitor their mood, stress, sleep, study habits, and motivation while identifying potential burnout risks through a weighted scoring system.

## Features

- 📊 Burnout risk assessment
- 😊 Mood tracking
- 😴 Sleep tracking
- 📚 Study habit tracking
- ⚡ Motivation tracking
- 📈 Analytics and charts
- 🔥 Streak tracking
- 🏆 Achievement badges
- 📥 JSON and CSV data export
- 🌙 Dark/Light mode
- 💾 Browser-based data persistence using localStorage

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js
- LocalStorage
